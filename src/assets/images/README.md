# Images

Put your profile photo here as **`portrait.jpg`** (or `.png`, `.webp`).
A 4:5 portrait crop of at least 800 × 1000 pixels works best. The site resizes it
and converts it to AVIF/WebP automatically. After adding it, run `npm run og-image`
to refresh the image used when the site is shared on social media.

Figures for paper pages can also live here; see the README ("Figures on a paper page").
